LeRobot 安装链：git clone（gh-proxy）→ pip install -e（清华源）→ 幻尔主臂插件 lerobot-teleoperator-rebot-arm-102 + Seeed 从臂插件 lerobot-robot-seeed-b601 + motorbridge → Web/相机依赖。 所有 pip 均带 --timeout 15 --retries 2，git 带低速超时保护（Ubuntu 额外用 GNU timeout 兜底）。 检测到系统已安装 LeRobot 时，点检测卡里的「一键安装 LeRobot」会直接复用、跳过克隆与主程序安装， 只补真正缺失的依赖；需要完整重装请用「强制重新安装」。安装启动后，本卡片会持续显示步骤、耗时、 最近输出与进度条，即使命令暂时没有输出也有心跳提示，可随时点进度条上的急停终止。
