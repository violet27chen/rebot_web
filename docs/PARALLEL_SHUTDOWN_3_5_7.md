# 双臂并行慢速收工 · 3.5.7

一键「收工归零并失能」及 B601 双臂插件的 disconnect 现在并行处理左右臂。覆盖遥操作、采集、ACT 策略评估正常结束，以及正常停止触发的清理流程。单臂只处理所选从臂；关闭自动回零的任务仍保持原有姿态保持设置。强制断开设备仍走原有立即释放路径。

两臂在各自独立 CAN 总线上工作。开始前完成实测反馈检查；一键收工还校验控制模式。在底座/腕部、肩肘、夹爪三个阶段，按两侧较大的位移计算共同的低速平滑轨迹时长。近侧放慢，不提高远侧速度追赶。每阶段都等两侧确认到位再继续，最终两侧确认归零后进入失能。

阶段等待期间继续校验反馈、发送保持目标；不会提前回零下一阶段。任一侧受阻、失去反馈或操作中断会取消另一侧继续收回，未确认到位不盲目失能。所有工作线程退出后才返回，避免主线程提前回收仍在使用的串口。左右 CAN 指令和反馈存在通信及调度时差；这不是硬件级同一时刻触发。

已安装的 editable B601 插件同时更新了自动收尾路径。仓库提供 `vendor_patches/parallel_shutdown.patch` 和共享协调模块，换环境后使用所选 LeRobot Python 运行：

```bash
python scripts/apply_slow_homing.py
```

此脚本只检查和修改本地源码，不连接硬件；不兼容的源码会在 patch dry-run 阶段报错。重复执行不会重复打补丁。

测试使用模拟电机、独立虚拟时钟和已安装驱动的方法体，覆盖并行启动、不同距离的共同耗时、全部到位后的失能、反馈缺失、单侧受阻取消另一侧、连接失败后清理及仅剩单侧总线。未执行真实机械臂运动测试。
