# 3.5.4：Loss 坐标与模型评估

Loss 图的 X 轴为 ACT 的训练步数（Step），Y 轴为损失值（Loss）。YOLO/OpenCV 的结构化训练指标按训练轮次（Epoch）显示；日志没有明确训练位置时，标为指标序号。图内和图下方均显示坐标轴名称。

保留最近 600 个训练位置时，坐标仍为原始 Step。同一步重复输出更新该位置的最新值；乱序位置、旧任务的重放不会让当前曲线倒退，新任务有独立曲线。训练与日志页面使用相同逻辑。后端可解析 `10K`、`10.2K`、`1M`、逗号分隔及科学计数法。官方 LeRobot 训练入口通过一个薄包装调用，将原先取整的 `step:10K` 日志改为精确整数，其余指标和训练流程仍由官方入口执行。

## 模型选择与离线评估

「模型训练」的微调参数中，下拉选择完整的模型检查点后自动填入已有模型路径；可以刷新列表或手动填写外部路径。「模型产出」提供每个 ACT 检查点的「用于微调」和「离线评估」。

离线评估位于「模型训练」的「离线模型评估」卡片。弹窗选择模型、测试数据集、剧集编号、采样帧数和 CPU/CUDA；参数自动保存。独立进程读取录制数据的相机画面与状态，加载模型及其保存的处理器，均匀采样并进行推理，不执行串口/CAN 或机器人动作。

结果包含原始动作 MAE/RMSE、最大误差、各关节误差、归一化 L1 及每帧模型推理时间。计算时排除动作填充帧；归一化 L1 使用部署推理结果，不包含训练 Loss 中的 KL 项。原始误差沿用数据集的动作单位。报告保存在 `outputs/model_evaluations/`，切页或后端重启后可以重新读取。应选择未参与训练的数据；离线拟合误差不等于实机快递分拣成功率。

## 真机策略评估与收工

当前 B601 双臂插件把共享相机放在左子臂，再统一为观测加 `left_` 前缀。因此检查点的 `left_左`、`left_深度相机`、`left_右` 分别对应配置中的「左」「深度相机」「右」。匹配时保留设备路径并只让插件加一次前缀。相机名称有重复或规则不一致时，仍拒绝猜测设备。

「快递分拣」页展开「高级：独立 ACT 真机评估」，可使用「一键收工归零并失能」。确认目标串口后，若当前仍为策略评估任务，先请求正常停止、等待清理和串口释放，再启动既有慢速归零任务；到位后失能。任务或端口变化、其他任务占用、清理超时都会中止后续操作，不强制杀掉其他任务。

验证包括解析器、任务绑定、相机前缀、离线参数与误差计算单元测试；浏览器模拟测试覆盖坐标保留、下拉自动填入、评估结果、二次确认、先停后归零及移动端。另以临时 LeRobot 数据集、真实小型 ACT 权重和保存的处理器完成了 CPU 离线运行；没有向实物机械臂发送测试动作。
