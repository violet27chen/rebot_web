# ACT目标保护与视频收尾 · 3.5.12

实际日志有两个独立异常：首先模型目标与实测角度超过统一30°阈值；随后 VideoEncodingManager 在PNG线程仍写盘时递归删除目录，产生 Directory not empty，掩盖原始策略错误。

只读离线加载用户的 tese1/020000 检查点，在训练数据 all_1 第一帧进行CPU预测：右夹爪的正常关闭目标与该帧实测位置相差约46.24电机度，其他关节偏差小于14°。这证明统一30°阈值会拒绝合法夹爪开合，不能据此证明用户最新一次失败一定只有夹爪原因。

异步限幅现在使用具体关节名称和配置中的物理限位。六轴仍保留30°绝对姿态差保护；只有明确命名为gripper且已知物理行程时，夹爪绝对目标允许其实际行程，每帧运动仍保持原电机角度限速。预测/实测严重越过物理限位仍拒绝，模型边界5°以内的小幅越界按原从臂软限位行为裁剪。错误会报告关节名、目标、实测值及阈值，不再只打印笼统的30°。

视频收尾先等待图像写盘任务完成、停止并加入写盘线程，再编码已提交剧集和关闭数据写入器。异常退出保留未完成剧集图片，不伪造剧集完成；不递归删除仍可能被写入的目录。清理自身出错时记录次级错误，原始策略异常仍继续传播。正常退出只移除空目录。

本次没有恢复失败的评估数据为完成剧集，没有重置编码器，也没有运行模型驱动电机。后续如果报出具体六轴关节偏差，需核对该模型的示教入口、相机对应关系和当前姿态；不能靠扩大所有关节阈值强行执行。
