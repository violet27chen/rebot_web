# v3.3.0 · build 20261113.3

修复“主从臂连接”残留“正在加载可选数据…”：公共首屏逻辑在下拉框旁插入占位，连接页只替换选项，没有清理旁边的占位。现在填写每个串口选择器前清除占位、加载类及相关状态。设备配置初始化与串口扫描分离，扫描失败不再阻断模式切换、参数显示和自动保存；配置本身失败则显示可重试错误。

新增 Electron 桌面客户端，详见 [desktop/README.md](../desktop/README.md)。Ubuntu `.deb` 与 Windows 免安装 `.exe` 均可启动本机后端，复用现有控制台与单一视觉进程；硬件仍由本机后端访问。

桌面模式将未提交表单草稿持久保存在客户端存储，断网或关闭应用后可恢复；普通浏览器继续使用原来的会话草稿隔离。

客户端优先复用已有本机控制服务；本机服务未启动时，在配置允许的情况下可分别通过 systemd 或 Windows 子进程启动。Windows 与 Linux 控制服务均可连接。私有环境配置、密钥、训练数据和模型不进入安装包。

版本号、HTML 无缓存策略和全部静态资源版本更新至 3.3.0。桌面连接设置自动保存，关闭客户端前处理待保存设置。用户未要求的硬件验收不执行。
