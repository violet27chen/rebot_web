# ACT 微调与页面切换（3.5.3）

## 使用已有 ACT 模型继续学习

1. 在「模型训练」选择 LeRobot，训练方式选择「在已有模型上微调」。也可以在「模型产出」直接点「用于微调」。
2. 选择同一技能的已有 `pretrained_model` 检查点，或填写本地模型目录。支持训练输出根目录、检查点目录以及 `config.json` 路径，系统会解析到权重目录。
3. 选择追加了示教数据的数据集，或另一个同技能数据集。ACT 会检查模型策略、权重文件、动作与状态维度、相机名称、数量和分辨率；保持原有关节顺序。模型路径与训练参数自动保存。
4. 填写**本次**微调步数。ACT 学习率填 0 时沿用检查点配置；填写正值时同时覆盖策略和视觉骨干学习率。
5. 点「检查模型与数据集兼容性」，再「开始微调」。启动时会再次检查。原输出目录已存在时自动生成同级的新微调目录，启动信息显示实际保存位置。

微调通过官方 `lerobot-train --policy.path=...` 加载已有策略权重，保留 ACT 结构，不注入 VLA 专用的 256×256 相机特征。新任务的优化器与步数重新开始；处理器和数据统计按当前 LeRobot 训练实现加载、更新。原模型文件不会被覆盖。

「断点续训原任务」用于恢复原任务的优化器、步数和配置。要使用新增数据学习，应选择微调。新一轮步数从 0 开始不代表模型权重从零初始化。

推拢、盒子翻面和袋子翻面仍应使用各自的数据和模型；新增示教与原技能数据一起训练有助于减少遗忘。系统不会自动混合不同技能或自动合并数据集。ACT 微调目前需要可读取的本地检查点；Hub 模型需先下载。原有 SmolVLA Hub 基础模型入口保留。

## 页面切换

切换页面及浏览器前进、后退时重置内容区滚动位置；不重建常驻摄像头和官方 3D 场景。内页根据实际内容高度通知外层，避免上一页 iframe 高度造成无法缩短的底部空白，旧页面的延迟高度消息也不会覆盖新页。

## 验证与加载更新

- `tests/test_training_finetune.py`：验证微调与从头训练命令、兼容性拒绝、独立输出目录、旧权重保留、忙碌任务保护及学习率校验。训练进程使用替身，不占用 GPU 或机械臂。
- `tests/browser/training-finetune.cjs`：模拟所有设备与训练接口，验证选模型、微调与从头训练、自动保存、失败时不启动、页面缩短和滚动重置、常驻监视与移动端宽度。

更新了前端缓存版本。当前已有训练运行时不重启后端，不中断训练；完整微调 API 需在训练结束后重启服务加载，再刷新界面。
