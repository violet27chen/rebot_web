# 3.4.1 零点调整服务修复

日志中的零点启动请求在 11:12～11:14 返回 HTTP 404，当时请求由旧进程 605907 处理：磁盘上的前端先更新，运行中的后端尚未加载新路由。旧服务于 11:16 更换为进程 630851。该错误表示接口不存在，不能据此认定左从臂或串口不存在。

本次增加只读 `/api/devices/zero/capabilities`，页面加载时检查实际运行服务的 API 能力、版本与工作程序文件。未就绪时禁用设备操作并显示明确错误，提供“重新检测服务”；检测不打开串口、不启动硬件任务。

HTTP 错误保留状态码，零点界面分别显示接口缺失、任务结果过期和操作结果未确认。任务响应缺少编号时不继续请求 `job_id=undefined`。所有失败路径均不自动重发设零或失能命令。操作期间锁定目标从臂和关节选择。

版本更新为 `3.4.1+20261114.2`，同步更新前端资源版本。真实 API 链路测试通过安全的模拟子进程验证启动、任务编号、结果读取与结束；浏览器模拟覆盖接口 404、服务恢复、结果过期与二次确认，不接触真实设备。
