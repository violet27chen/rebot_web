# v3.2.0 · build 20261113.2

实时监视的 RGB、深度图和 3D 场景均支持点击放大。模态框可通过 ×、空白遮罩或 Esc 关闭。RGB / 深度放大通过画布镜像现有解码帧，不创建额外 MJPEG、SDK 或相机连接；深度图可在大图内点击读取毫米值。3D 放大将原来的 WebGL 画布临时移入模态框，关闭后归位，场景与实测关节反馈不断开。

常驻模型改为一个 WebGL 场景。单臂模式只显示一台；双臂模式在同一场景内显示两台同向朝前的官方模型，独立接收左右关节反馈。模型继续使用现有 `reBot-DevArm_fixend.urdf` 与对应 STL；URDF 与网格加载完成后复制官方 URDF 对象，保持两臂关节相互独立。没有自绘机器人模型或镜像右臂。

“基座位置”设置自动保存，有两种来源：

- **共同坐标系下的左右底座位置**：输入两底座旋转中心的 XYZ，自动计算 `d = sqrt(dx² + dy² + dz²)`，并保留相对前后位置和高度差。
- **实测中心距**：直接输入中心距，按同向并排放置。

工作台坐标约定为 X 向右、Y 向前、Z 向上，单位 mm。渲染使用 m，因此坐标除以 1000；仅对两个底座位置作共同的居中平移，不改变真实相对距离。两模型应用相同的朝前旋转，不镜像。

设置位于独立的 `monitor_layout` 配置节，不改变控制对象、串口或连接状态。`GET /api/monitor/layout` 返回设置及服务端计算结果。部分坐标可自动保存，但必须全部提供且两底座不重合后，才会作为真实坐标布置。

**当前项目未包含两底座在共同坐标系中的标定外参。** 各臂局部底座均为零点；末端 FK 也不能给出两个底座的摆放关系。因此没有从关节角或未标定图像编造“真实间距”。缺少坐标或实测中心距时，双臂仍显示在一个场景，且明确标记为未标定布局示意。示意间距不写入配置，也不作为实测数据返回。

按用户要求停止硬件验收。该版本只完成必要的语法检查；不运行机器人动作、自动标定或硬件验收脚本。版本号、页面静态资源版本和禁止缓存的 HTML 均已更新，刷新网页可加载新界面。
