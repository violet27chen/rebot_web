## 固定俯视相机先标定

摄像头页的「固定俯视 · RGB-D 空间标定」用于采样与求解，不发电机指令。先选择对应彩色设备，冻结一组 RGB 和深度，再读取 SDK 当前模式的深度内参。

1. RGB 内参：至少八张棋盘，覆盖不同位置和倾角，填真实方格边长。
2. RGB-D 对齐：至少八对同一物理点的 RGB 像素 / 深度像素。
3. 深度到工作台：至少六对三维点，必须覆盖不同高度，坐标使用米。
4. 左右臂基座到工作台：各至少六对实测点。FK 按官方 DM URDF 的 `end_link` 计算，只有该参考点与采样点重合时才能配对，不能把夹爪任意边缘当成此参考点。
5. 工作台 Z 轴垂直向上，填写真实工作区范围与桌面平面；用额外测量点验证，再确认各项标定。

单张深度平面不能确定相机平面内方向、RGB 对齐或机械臂基座位置。本版本不再把假定安装高度、基座间距、相机平移或虚构误差自动确认为标定。运动要求对应点求解记录完整，旧版假定几何需要重新标定。

没有标定时仍可获取 YOLO 画面和候选码，但三维坐标保持无效，执行被禁止。没有深度时只能预览，默认包裹高度不能作为实测高度驱动本流程。

## 包裹坐标与面单证据

策略评估页中「包裹定位与技能执行」使用与全局监视相同的相机进程：

1. 根据配置的包裹类别和面单类别过滤 YOLO 输出，不把普通前景连通域虚构成已分类包裹。
2. 使用原始 `uint16` 毫米深度和标定外参，投影到 RGB 检测框，过滤桌面 / 深度空洞，得到工作台坐标、桌面相对高度和范围；检测冻结帧直接标注 XYZ。
3. 逐包裹读取 Code128、QR 等候选码；单号仅在匹配用户配置的正则规则时确认。普通二维码不自动当成快递单号。
4. 对面单或已匹配单号码的区域检查深度平面。至少 16 个点、平面 RMS ≤ 6 mm、相对桌面法向倾斜 ≤ 25°、与包裹顶面高度差 ≤ 25 mm，才形成「顶面已确认」证据。薄条码区域不足以确定法向时保持待检查。

| 面单状态 | 含义 | 推荐 ACT 用途 |
| --- | --- | --- |
| `top_readable` | 顶面已确认，且唯一单号匹配规则 | `sort` 分拣 |
| `top_unreadable` | 顶面已确认，单号尚未确认 | `scan` 平整 / 调整后读取 |
| `needs_inspection` | 未确认顶面，或多个候选单号存在歧义 | `flip` 检查 / 翻面查找 |

没有读到单号不等于面单一定朝下。这里不提供通用 OCR；纯文字单号需要另接 OCR，或重新采集能读出条码的画面。

## 独立 ACT 登记与执行

每个技能独立采集、独立训练。登记 `class_name`、`role`、`label_condition` 后，类别与面单条件必须唯一匹配；缺失或重复时拒绝启动，不选择任意模型，也不自动切换到另一个操作流程。

仍需填写真实训练区域、14 维原始电机起始弧度、相机映射、数据集 `meta/info.json` 和标定版本。检查点必须是 14 维 ACT，训练状态 / 动作关节名必须与双臂一致。当前姿态与整个标定工作区不能自动代表模型的训练范围。

接近使用官方 DM URDF 的 IK / FK，轨迹检查桌面、工作区和双臂连杆间距；ACT 每一步也通过对应几何检查。软件连杆间距模型不代表已完成全场景碰撞验证，尚需核对真实夹爪 TCP、臂体尺寸和周围设备。

在训练区域外优先进行限距规则推拢，再获取 RGB-D 检查是否到位；如果推拢改变面单条件和匹配技能，停止并要求重新预演。执行前重新检测目标位置、面单状态和单号，防止使用旧快照。

CAN 独立进程提供重力前馈、力矩 / 温度 / 指令时效 / 浏览器心跳检查。浏览器或网络断开不再发送推进目标；故障锁存，不自动恢复。浏览器全局外壳续心跳，切换功能页不影响会话。执行完成后保持姿态，再通过全局收工按钮归零并失能。

## 慢速归零与停止

统一处理全局收工、LeRobot 遥操作 / 录制的正常退出、SDK 控制器及旧控制接口：

- 从每一阶段的**当前实测位置**开始，采用最小加加速度轨迹，连续轨迹起止速度与加速度为零。
- 默认速度上限 **0.15 rad/s（约 8.6°/s）**，加速度上限 **0.20 rad/s²**；原生位置命令也使用慢速上限，不沿用运行期高速参数。
- 按底座与腕部、肩肘、夹爪分阶段收回；大行程夹爪不再压缩成半秒动作。
- 调度变慢时按顺序发送采样，不跳到终点追赶；跟踪误差、缺失反馈、温度或到位检查失败时，不再补发零位目标，也不把半途收回当成完成后失能。
- 正常停止只发一次退出请求，清理在后台进行，任务进度与相机继续更新；重复点击不会再次用 SIGINT 打断正在进行的慢速归零。
- 强制急停 / 一键杀占用进程只负责终止和释放，不偷偷启动归零运动。设置编码器零点是另一项明确确认的操作，不受回零轨迹替代。

## 软件验证范围

后端测试覆盖几何、标签顶面判断、Code128、条件技能路由、无标定拒绝、原始动作方向、慢速轨迹速度 / 加速度、真实驱动函数的模拟反馈、受阻中止与重复停止。官方 DM URDF 做 FK/IK 数值往返检查。浏览器回归拦截全部设备请求，覆盖自动保存、坐标与单号展示、预演及二次确认、标定采样与环境诊断。

本次开发没有执行真机运动，没有替用户填写空间标定、训练范围或认定技能在真机上已经成功。
